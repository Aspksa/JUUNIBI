# Центр обновлений JUUNIBI — безопасная установка и полёт файлов

Обновлятор скачивает содержимое выбранного commit GitHub во временную папку `.updates/staging`, сверяет размер и Git blob SHA-1, затем выполняет `npm ci`, `typecheck`, `test` и `build`. После успешных проверок он создаёт `.updates/ready.json`.

При следующем запуске `JUUNIBI.bat` модуль `scripts/apply-update.mjs` **до старта сервера** проверяет *все* staged-файлы и SHA, затем создаёт резервные копии существующих файлов, атомарно заменяет файлы и записывает `.juunibi-version`. Ошибка установки вызывает восстановление из резервных копий и возврат маркера версии. Если часть отката не удалась, показывается отдельная ошибка, а не сообщение об успехе.

Защищены `.env`, `data/`, `.runtime/`, `.git/`, `.updates/`, `node_modules/`, служебный маркер версии, недопустимые и выходящие за корень пути, симлинки назначения, имена устройств Windows. Старые файлы репозитория **не удаляются автоматически**: удаление без отдельного проверенного diff рискованно.

## Отображение

Вкладка «Обновление проекта» позволяет выбрать простой, визуальный и технический режимы. Список файлов берётся из настоящего Git tree; события скачивания и установки записываются в `.updates/events.jsonl`. Движущаяся карточка соответствует реально полученному `file_download_done` или `file_install_done`; **успешная установка** отмечается только после события `file_install_done`. Интерфейс не управляет файловым копированием. При `prefers-reduced-motion` анимация отключается.

## Проверки

- `node --test scripts/apply-update.test.mjs` — путь, защищённые файлы, проверка SHA, симлинки, успешная установка, события;
- `npm test` — включён тестовый набор установщика и существующие тесты всех рабочих пространств;
- `npm run typecheck`, `npm run build`.

Требуется отдельно проверить на реальной Windows-машине: файл, занятый процессом (Windows lock), права каталогов, восстановление после аварийного отключения питания и визуальный UX с сотнями файлов. Автоматические CI-проверки не заменяют эти тесты.

**Ограничение:** установка происходит во время следующего запуска, а не сразу при завершении анимации; журнал обновляется периодическим опросом, без WebSocket. Удаление файлов, приостановка скачивания и полный health-check после запуска не реализованы.
