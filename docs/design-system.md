# Дизайн-система JUUNIBI

Живой справочник открывается в приложении: **меню слева → «Дизайн-система»** (`#/design`). Он читает значения из настоящих токенов, поэтому всегда совпадает с кодом и меняется вместе с темой.

## Структура

| Файл | Роль |
|---|---|
| `apps/web/src/design/tokens.css` | **Единственный источник** цветов, отступов, скруглений, шрифтов, теней, анимации, слоёв (z-index), размеров. Светлая и тёмная темы. |
| `apps/web/src/design/base.css` | Сброс, типографика, фокус, утилиты (`.muted`, `.row`, `.stack`, `.sr-only`), «уменьшить анимацию». |
| `apps/web/src/design/components.css` | Компоненты: кнопки, поля, переключатели, сегменты, метки, уведомления, карточки, списки, прогресс, `kbd`, `prose`, блок кода. |
| `apps/web/src/style.css` | Раскладка приложения: меню, страницы, аватар, окно чата, обновление. Только токены. |
| `apps/web/src/ui.ts` | Типизированные фабрики компонентов (`button`, `field`, `segmented`, `alert`, …) — **единственное место, знающее имена классов**. |
| `apps/web/src/design/contrast.ts` | Расчёт контраста WCAG (тесты и справочник). |

## Правила

1. **Только токены.** В `style.css`, `base.css`, `components.css` нельзя писать `#fff`, `rgb()`, `hsl()` и «голые» `z-index` — только `var(--…)`. Это проверяет `test/design.test.ts`.
2. **Новый цвет = новый токен в обеих темах** и пара в таблице контраста теста.
3. **Контраст:** текст ≥ 4.5:1, крупные элементы и графика (кольцо аватара, фокус) ≥ 3:1 — в светлой и тёмной темах (WCAG AA). Тест падает, если пара не проходит.
4. **Золотой (`--brand`)** — только образ персонажа, фокус и прогресс. Золото как текст — `--brand-text`.
5. **Цвет не единственный носитель смысла:** у ошибок и успеха есть иконка или текст.
6. **Фокус клавиатуры** всегда виден (`:focus-visible`); анимации отключаются при `prefers-reduced-motion`.
7. Новые компоненты: добавить CSS в `components.css`, фабрику в `ui.ts`, пример в `pages/design.ts`.

## Токены (кратко)

- **Цвет:** `--bg --surface --surface-2 --fg --muted --line --hover --hover-2 --accent --accent-fg --brand --brand-fg --brand-text --danger --danger-fg --ok --warn --info --code-*`
- **Отступы (шаг 4 px):** `--sp-1 … --sp-12`
- **Скругления:** `--r-sm --r-md --r-lg --r-xl --r-pill`
- **Шрифт:** `--font --font-mono`, размеры `--fs-xs … --fs-3xl`, начертания `--fw-*`, интерлиньяж `--lh-*`
- **Тени:** `--sh-1 --sh-2 --sh-3`; **анимация:** `--dur-1 --dur-2 --ease`
- **Слои:** `--z-raised --z-drawer --z-fab --z-scrim --z-nav --z-chat --z-toast --z-overlay`
- **Размеры:** `--nav-w --content-max --chat-max --control-h --icon-btn --fab-size`

## Компоненты

Кнопка (`primary`, обычная, `ghost`, `danger`, `sm`), иконочная кнопка, поле ввода (`field`), переключатель, флажок, сегментированный переключатель, метка (`tag`), счётчик (`badge`), уведомление (`alert`: ok/warn/danger/info), карточка/панель, статус-карточка, список, прогресс, `kbd`, текст ответа (`prose`) с блоком кода.

## Как менять тему/цвета

Правьте значения в `tokens.css` (блоки `:root`, `@media (prefers-color-scheme:dark)` и `:root[data-theme=dark]` должны совпадать — это тоже проверяется) и запустите `npm test -w @juunibi/web`.
